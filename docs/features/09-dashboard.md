# 통계와 대시보드 개발 문서

[문서 인덱스](../README.md) · [전체 개요](../PROJECT_DECISIONS.md) · [개발 순서와 미정 사항](../ROADMAP.md)

문서 ID: F09

상태: ECharts 선택 완료, 설치 및 업무 화면 구현 전

이 문서의 상세 기능, 데이터와 완료 기준은 현재 요구사항을 개발 단위로 풀어쓴 설계안이다. 구현 후 검증 기준은 아직 실행 결과가 아니다. 사용자 확정사항과 기존 적용 기록은 별도로 표시한다.

## 목적과 범위

공통 집계 결과를 ECharts로 표시하고 상세 업무 자료로 연결한다.

- 매출·비용·손익·현금 흐름·채권채무의 표시
- KPI, 표와 차트 간 집계 조건 및 금액 일치

## 입력과 결과

| 구분 | 내용 |
| --- | --- |
| 입력 | 회사, 기간, 필터와 서버 집계 결과 |
| 결과 | KPI 카드, 표, 차트와 원장·재무제표 연결 |

## 데이터와 처리 규칙

- ECharts는 선택 완료이며 설치·구현 전 상태를 유지한다.
- 기본 Canvas와 필요한 모듈만 가져오는 방식을 계획한다.
- 회사·기간·표시 단위와 집계 버전을 표·차트에서 공유한다.
- 차트 성능은 실제 데이터와 대상 Windows 환경에서 측정한다.

## 기존 결정과 상세 요구사항

아래 내용은 종합 문서에서 옮긴 결정 및 요구사항이다. 기술 버전과 적용·검증 기록의 기준일은 2026년 10월 5일이며, 이번 문서 분리 작업에서 기능이나 외부 서비스 상태를 재검증한 결과는 아니다.

### 통계와 그래프 선택

기본 그래프 라이브러리는 **Apache ECharts**로 정한다. 작성일에 [공식 최신 릴리스](https://github.com/apache/echarts/releases/latest)가 가리키는 안정 버전은 [6.1.0](https://github.com/apache/echarts/releases/tag/6.1.0)이다. 도입 시점에는 버전을 다시 확인하고 잠금 파일로 관리한다.

선택 이유는 회계 대시보드에 필요한 차트 범위와 대량 데이터 대응을 함께 고려한 판단이다. 모든 조건에서 가장 빠르다는 실측 결과를 뜻하지 않는다. ECharts 공식 문서는 많은 요소를 그리는 경우 Canvas를 권장하며, Canvas와 SVG를 선택할 수 있다. 또한 필요한 차트와 구성 요소만 가져오는 방식을 제공한다. [렌더러 선택 지침](https://echarts.apache.org/handbook/en/best-practices/canvas-vs-svg/), [부분 가져오기 지침](https://echarts.apache.org/handbook/en/basics/import/)

| 업무 지표 | 권장 표시 |
| --- | --- |
| 월별 매출과 비용 | 비교 막대 그래프 |
| 손익과 현금 흐름 추이 | 선 또는 영역 그래프 |
| 계정별 비용 비중 | 도넛 그래프 |
| 매출과 이익률 비교 | 막대와 선의 복합 그래프, 단위별 축 |
| 미수금과 미지급금 | 기간 또는 거래처별 막대 그래프 |
| 총액과 건수 | KPI 카드와 상세 표 |

통계 집계는 서버와 데이터베이스에서 처리하고, 그래프에는 집계 결과를 전달하는 것을 권장한다. 기본 합계와 건수는 PostgreSQL 집계 기능을 활용한다. 별도의 브라우저 통계 연산 라이브러리는 현재 선택하지 않았다. [PostgreSQL 집계 함수 문서](https://www.postgresql.org/docs/current/functions-aggregate.html)

구현 기준은 다음과 같다.

- 기본 렌더러는 Canvas로 두고, 필요한 차트 모듈만 불러온다.
- 전표 원본 전체를 차트에 전달하기 전에 서버에서 기간별로 집계한다.
- 표와 그래프는 동일한 집계 기준과 결과를 사용한다.
- 축의 만원 또는 백만원 단위와 툴팁의 정확한 금액을 구분한다.
- 음수, 0, 데이터 없음의 의미를 구분한다.
- 반응형 크기와 Pretendard를 공통 차트 컴포넌트에서 관리한다.
- 실제 데이터로 첫 표시 시간, 갱신 시간, 메모리 사용을 측정하고 Windows에서도 확인한다.

대량 시계열이나 실시간 선 그래프에 특화된 후보는 uPlot이다. 다만 [uPlot 공개 성능 비교](https://github.com/leeoniya/uPlot#performance)는 2023년 작성된 자체 벤치마크이므로 최신 라이브러리 전체의 성능 순위로 사용할 수 없다. 지금 단계에서 추가 도입 대상으로 정하지 않았다.

현재 [package.json](../../package.json)에는 Recharts, Chart.js, react-chartjs-2가 남아 있고 ECharts는 없다. 설치된 Recharts는 `2.15.4`로 확인했다. [기존 ChartJs 화면](../../src/pages/charts/ChartJs.tsx)은 CSS와 SVG로 만든 예시이며, 해당 차트 라이브러리를 사용한 회계 화면이 아니다. ECharts 도입과 기존 의존성 정리는 후속 구현 작업이다.
