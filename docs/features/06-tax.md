# 세무 집계 개발 문서

[문서 인덱스](../README.md) · [전체 개요](../PROJECT_DECISIONS.md) · [개발 순서와 미정 사항](../ROADMAP.md)

문서 ID: F06

상태: P-04 첫 세무 범위 확정, 세무 집계·계산·검토 기능 구현 전

이 문서의 상세 기능, 데이터와 완료 기준은 현재 요구사항을 개발 단위로 풀어쓴 설계안이다. 구현 후 검증 기준은 아직 실행 결과가 아니다. 사용자 확정사항과 기존 적용 기록은 별도로 표시한다.

## 목적과 범위

회계 장부와 세무 조정 근거를 연결하여 대상 기간의 신고용 금액을 집계한다.

- 적용 연도·세목별 집계와 세무 조정
- 계산 근거 및 사용한 규칙 버전 추적

## 입력과 결과

| 구분 | 내용 |
| --- | --- |
| 입력 | 회사, 세목, 사업연도·대상 기간, 확정 장부와 조정 자료 |
| 결과 | 신고용 집계, 조정 명세와 계산·규칙 선택 근거 |

## 데이터와 처리 규칙

- 아래 P-04 정책의 대상 국가·세목·기간·신고 종류에 맞추어 계산 항목과 신고용 자료를 상세 설계한다.
- 회계 규칙과 세무 규칙을 구분하고 조정 항목의 근거를 보관한다.
- 규칙 선택과 개정 적용은 회계기준 및 세법 변경 관리 문서를 참조한다.
- 과거 확정·신고 결과는 자동 덮어쓰지 않고 재계산 및 수정 결과를 별도 보존한다.

## 사용자 위임으로 확정한 첫 세무 범위

확정일: 2026-10-05. 사용자 지시: “이것도 일반적으로 통용되는 방식으로”. P-04의 추천 범위를 제시한 뒤 받은 **세무 정책 선정 위임**이며, 에이전트가 기존 국내 법인 회계 범위와 공식 신고 안내를 참고하여 아래 값을 선정했다. 각 값은 사용자 위임에 따른 프로젝트 결정이며 모든 법인의 납세 의무·특례를 일괄 판정한 결과가 아니다. 이후 확정한 P-10 금액 정책은 [공통 기반](08-platform.md#확정한-금액-정책)을 따른다.

| 항목 | 확정한 정책 |
| --- | --- |
| TAX-01 국가·기업 | 대한민국의 국내 영리·비금융 법인을 대상으로 한다. P-03의 일반기업회계기준 적용 기업 범위와 연결하고 회사별 사업자·사업장·과세 유형을 기록한다. 개인사업자·비영리·외국법인·연결납세·국제조세 특수 계산은 첫 범위에서 제외한다. 일반과세 법인의 부가세 자료를 우선 지원하며 간이과세·면세 전용 사업의 신고 기능은 포함하지 않는다. |
| TAX-02 첫 세목 | 부가가치세, 법인세, 법인지방소득세의 3개를 지원한다. 국세·지방세를 구분하고 법인지방소득세를 법인세 금액의 고정 비율로 단순 대체하지 않는다. 원천세·급여·연말정산·개인 종합소득세·기타 지방세는 후속 범위이다. |
| TAX-03 신고 종류 | 부가세 예정신고·확정신고 자료와 예정고지 대상 여부·고지액 반영을 지원한다. 모든 법인이 예정신고 의무를 가진다고 가정하지 않는다. 법인세와 법인지방소득세는 각 사업연도 정기신고용 자료를 지원한다. 법인세 중간예납·부가세 조기환급·폐업 특수 신고·기한후신고·수정신고·경정청구의 자동 산출·제출은 첫 범위에서 제외한다. 과거 자료 정정 이력과 검토용 재계산은 보존하되 정식 수정신고 지원으로 표시하지 않는다. |
| TAX-04 최초 적용 기간 | 부가세는 2026년 과세기간, 법인세·법인지방소득세는 2026년에 시작하는 사업연도부터 지원한다. 사업연도 시작일·종료일과 거래일을 기록하고 그 기간에 실제 적용되는 법령·경과조치·서식 버전을 선택한다. 2025년 이전 세무 계산은 첫 범위에서 제외한다. 이후 연도는 검토·승인된 규칙 버전이 준비된 경우에만 지원하며 2026년 규칙을 자동 복사하지 않는다. |
| TAX-05 자료·계산 범위 | 확정 장부와 증빙에서 매출·매입 및 세무 집계 기초 자료를 산출하고, 공제 여부·세무 조정·기납부세액과 근거를 기록한다. 법인세는 결산 손익에서 과세표준·세액까지의 조정 명세를, 법인지방소득세는 해당 규칙과 사업장별 안분 자료를 별도로 추적한다. 지원하는 공제·감면·특례와 계산 항목을 공개하며 미지원·근거 누락·규칙 충돌은 수동 검토 대상으로 표시한다. 검토하지 않은 항목을 0으로 처리하거나 완성된 신고자료로 표시하지 않는다. 세율·한도·공제·가산세의 구체적 계산식은 F06·F13에서 공식 근거와 검증 사례를 갖추어 구현한다. |
| TAX-06 회사 담당·검토 | 회계 담당자 또는 회사 관리자가 회사의 신고자료와 조정 근거를 준비한다. 회사가 지정한 세무사 등 자격·전문성을 확인한 세무 검토자가 내용을 검토하고, 회사 관리자가 신고자료를 최종 확인한다. 검토 담당자를 지정하기 전에는 자료를 초안으로만 유지한다. 실제 담당자는 회사 설정으로 지정하고 검토자·검토 시각·의견·최종 확인자와 버전을 기록한다. 시스템의 외부 세무사 역할만 부여했다고 전문 자격을 확인한 것으로 간주하지 않는다. |
| TAX-07 공통 규칙 승인 | 서비스 공통 세무 계산 규칙은 지정된 세무 전문가가 검토하고 서비스 운영 관리자가 승인한 뒤 활성화한다. 회사 관리자의 자료 최종 확인 권한으로 전체 고객사의 규칙을 바꿀 수 없다. 규칙 검토·운영 승인의 실제 담당자 지정과 승인된 근거·테스트가 없으면 규칙을 활성화하지 않는다. 이 운영 책임 구분은 회사별 5개 역할과 별개이며 접근 제어는 F13·F08-13에서 설계·구현한다. |
| TAX-08 결과·제출 경계 | 웹 집계·조정·검토 자료와 Excel·PDF·인쇄를 제공한다. 공식 신고서 항목과 자료의 대응 관계, 적용 서식 버전을 기록하지만 첫 버전의 출력물은 신고 준비·검토 자료이다. 국세청 홈택스·위택스의 전자신고 파일 생성, 로그인 연동·자동 제출·납부는 포함하지 않는다. 검토·최종 확인 상태와 실제 신고·접수 상태를 구분하고 외부 제출의 접수증은 별도 기록한다. |
| TAX-09 보존·권한·검증 | 회사별 접근과 조회·다운로드 권한을 적용하고 확정한 자료·조정·규칙·서식 버전을 보존한다. 검토 뒤 장부·조정·규칙이 바뀌면 새 버전을 만들어 다시 검토하며 기존 최종 확인본을 덮어쓰지 않는다. 외부 세무 검토자는 지정 회사의 검토 의견을 기록할 수 있지만 그 자격으로 회사 최종 확인·전표 승인·회사 관리 권한을 받지 않는다. 세무 검토와 자료 최종 확인은 F06의 추가 작업으로 구현하며 P-02의 기존 전표 권한·회사 범위 제한은 유지한다. 금액·반올림은 P-10 확정 뒤 공통 계약을 사용한다. |

### 공식 근거와 프로젝트 선택의 구분

2026-10-05에 다음 공식 안내를 확인했다. 이 확인은 신고 유형을 구분하는 근거이며 특정 사업연도의 모든 세율·특례·신고 서식을 검증한 결과는 아니다.

- [국세청 부가가치세 개요](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7693&mi=2401): 법인사업자의 예정·확정신고와 소규모 법인 등의 예정고지 예외를 구분한다. 따라서 회사별 예정신고·예정고지 적용 조건을 관리한다.
- [국세청 법인세 개요](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7744&mi=2370): 내국법인과 각 사업연도 소득을 구분하고 공제·감면 등 신고 전 검토가 필요한 내용을 안내한다. 따라서 장부 집계와 세무 판단·조정 근거를 구분한다.
- [정부24 법인지방소득세 신고](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13100000067): 법인지방소득세의 별도 신고와 과세표준·세액신고서를 안내한다. 지방세 계산·신고자료는 별도 규칙으로 관리한다.

3개 세목의 첫 지원, 2026년 시작, 담당자의 검토·확인 절차와 자동 제출 제외는 제품 범위를 위한 프로젝트 선택이다. 실제 회사가 지원 제외 항목에 해당하면 해당 의무가 없어지는 것이 아니라 그 부분을 별도 세무 업무로 처리해야 한다. 기준 연도를 서비스 공통 기본값으로 관리하더라도 실제 회사·거래·기간·규칙 버전은 업무 데이터로 보존한다.

영향 작업: F01-01·05~08, F06-01~08, F08-11~13, F10-05·06, F13-01~09. [확정 기록](../PROJECT_DECISIONS.md#사전-결정-확정-기록)과 [구현 계획](../IMPLEMENTATION_PLAN.md)을 함께 참조한다. 세무 계산·권한·저장·검토·출력 기능과 실제 신고는 아직 구현·검증 전이다.

## 구현 후 검증 기준

- [ ] 회계 장부 금액에서 세무 조정을 거쳐 집계 결과까지 근거를 추적한다.
- [ ] 동일 입력과 동일 규칙 버전의 재계산 결과가 일치한다.
- [ ] 적용 규칙 누락·충돌과 지원하지 않는 세목을 명시적으로 처리한다.
- [ ] 개정 전후 및 사업연도 경계 사례를 승인된 예상 결과와 비교한다.

## 후속 구현 설계와 남은 결정

- P-04 정책에 따른 세목·기간별 계산 항목·조정·공제·감면·사업장 안분·공식 서식 매핑의 상세 설계 및 검증
- 회사별 실제 검토자와 서비스 규칙 검토·승인 담당자 지정, 검토 화면·권한·상태 전이의 구현. 담당자 미지정은 활성화·최종 확인의 차단 조건
- 확정한 P-10 공통 금액 정책과 세법별 반올림 예외의 구현·검증. 원천세·급여·자동 제출·특수 신고는 첫 범위 밖이며 별도 범위 확정 전 구현하지 않음

상세 의사결정은 [미정 사항 목록](../ROADMAP.md)을 함께 갱신한다. 새로운 기능이나 계약이 확정되면 이 문서를 수정하고 [인덱스](../README.md)의 범위·참조 경로도 갱신한다.
