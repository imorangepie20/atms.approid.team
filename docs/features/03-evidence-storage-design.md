F02 전체, 특히 전표/증빙 과거 연결까지 완료됐다는 뜻도 아니다.

현재 `server/prisma/schema.prisma`에는 증빙/첨부 모델이 없고 `src/lib/api.ts`에는 증빙 API가 없다. `server/src/auth/access-policy.ts`에는 기존 evidence.read/evidence.create가 있다. 관리자·회계 담당자·외부 세무사는 등록 권한, 다섯 역할 모두 조회 권한이 있으며 회사별 겸임/공통 제한을 그대로 재사용한다. 현재 거래처 API5개와 화면 코드를 다음 증빙 정책을 추정해서 확장하지 않는다.

## 공개 자료와 실제 환경의 구분

Cloudflare 공식 문서에서 R2의 [S3 호환 API](https://developers.cloudflare.com/r2/get-started/s3/), [버킷의 기본 비공개 상태](https://developers.cloudflare.com/r2/buckets/create-buckets/), [저장·요청 요금](https://developers.cloudflare.com/r2/pricing/)을 확인했다. 이 기능/가격 문서를 근거로 D1을 추천하며 우리 계정의 R2 활성화·버킷·접근 성공을 확인한 것은 아니다. 기존 Cloudflare Tunnel 구성이 R2 사용 계약이나 자격 증명 존재를 뜻하지 않는다. 이번에 버킷 생성·유료 가입·비밀 설정·실제 파일 업로드는 하지 않는다.

완료 원본을 보존하는 추천은 운영 정책 선택안이다. 일정 기간이 지났다는 이유로 원본을 자동 삭제하는 정책을 임의로 도입하지 않는다. 특정 보존기간을 새로 선택하면 그 범위의 요구사항과 근거를 확인한 뒤 별도 기록한다.
