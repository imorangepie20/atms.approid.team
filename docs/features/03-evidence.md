전표 초안 화면·홈서버 반영 부분 완료(2026-10-07): 사용자 “로그인완료”(api.ts 지정) 후 [B1~B8의 실제 브라우저 검증과 메뉴 수리](04-journal-draft-browser-design.md#실제-브라우저-검증과-b1-메뉴-수리-완료--2026-10-07)를 끝냈다. [최종 집계](../../.artifacts/implementation-f04-journal-browser/results.json)는 K1~K8 PASS다. 가상 계정2·거래처1·PDF1·초안2를 실제 UI로 등록하고 첫 초안의 적요 수정/연결 해제로 version1→2→3, 최종2초안·4분개·1연결·초안감사4건·번호/작성자/합계/원본 불변·새로고침을 DB와 대조했다. B1 메뉴 누락을 발견해 Sidebar 링크와 실제 메뉴 진입 시험을 보강하고 전체 검증을 다시 실행했다. 서버761·DOM154·Appearance16·배포 브라우저12시험과 build/타입/schema/lint 종료0, 보호306파일·정책5개·139체크·과거14산출물·기존 업무 행·13migration/27테이블을 보존했다. 정적 메뉴 수정만 기존 홈서버에 추가 반영했고 HTTPS200/미인증 초안401·배포 index 해시 일치를 확인했다. 승인/확정·원장 등 후속 기능과 전체 F03/F04/출시 체크는 유지한다. Hindsight는 기존30분 예약에 맡기며 이번 문서의 원격 반영은 별도로 확인하지 않았다.

전표 초안 화면 확정(2026-10-07): 직전 [B1~B8·기존 API5개·17파일·K1~K8·홈서버 반영](04-journal-draft-browser-design.md) 제시 후 사용자 “확정”(설계 문서 지정)으로 전체를 선택했다. 서버 계약/정책을 유지하고 승인된 화면·배포·가상 자료 검증을 진행한다. 실제 완료와 구분하며 기존139행을 유지한다.

전표 연결의 다음 화면 제안(2026-10-07): [완료한 초안 서버](04-journal-draft-foundation-design.md)에 이어 [B1~B8 화면/배포 설계](04-journal-draft-browser-design.md)를 준비했다. 전표 전체 수정 안의 증빙 연결/해제, 증빙 상세의 연결 초안 조회/상세 경로를 기존 원본/미리보기와 함께 검증한다. 기존 API5개·구현17파일·완료 검증8조건은 사용자 확정 대기이며 전체 F03 체크와 원본 보호 정책은 유지한다.

현재 개발(2026-10-06): V1~V5 승인 후 사용자 “성능좋은 라이브러리 추가는 네 재량이야”로 PDF.js 전환을 위임했다. [미리보기 묶음6조건 PASS](03-evidence-preview-design.md#pdfjs-수정-묶음의-검증-완료--2026-10-06): PDF2페이지·JPEG/PNG·수명/오류·화면375/768/1440을 검증하고 홈서버에 반영했다. 전표 연결/원장 경로 등 전체 F03 상위 체크는 유지한다.

첫 증빙 서버 기록(2026-10-06): 실제 R2 객체/API·ClamAV를 포함한 서버 8조건과 API 587개를 검증했다. [서버 실행 근거](03-evidence-foundation-design.md#실제-r2-연결-수정-후-전체-검증-완료--2026-10-06)를 따른다. 이후 첫 브라우저 화면 8조건도 [별도로 PASS](03-evidence-browser-design.md#b1b7-화면-부분-검증-완료--2026-10-06)했다.

문서 ID: F03

상태: 첫 서버·첫 브라우저 화면 각각 8조건 PASS, 미리보기·전표 연결/원장 경로 후속

첫 증빙 브라우저 화면은 사용자 “확정”(src/App.tsx 지정)으로 [B1~B7·기존 API 5개·13파일](03-evidence-browser-design.md)을 선택했다. 첫 화면 부분의 8조건·E2E234개·API587개 검증을 마쳤고 홈서버 배포 검증은 별도다. F03 상위 7개 항목은 미리보기·전표 연결/원장 경로 등이 남아 유지한다.

이 문서의 상세 기능, 데이터와 완료 기준은 현재 요구사항을 개발 단위로 풀어쓴 설계안이다. 구현 후 검증 기준은 아직 실행 결과가 아니다. 사용자 확정사항과 기존 적용 기록은 별도로 표시한다.

P-07 확정(2026-10-06): 직전 다섯 선택안에 대한 질문에 사용자 “확정”(src/lib/api.ts 지정)으로 [비공개R2 Standard/PDF·JPEG·PNG/10MiB·원본1개/완료 원본 보존·미완성24시간 정리](03-evidence-storage-design.md)를 선택했다. 별도 범위 확인 질문 뒤 다시 사용자 “확정”(같은 파일 지정)으로 [첫 증빙 서버 E1~E8·API5개·24파일·검증8조건](03-evidence-foundation-design.md)을 승인했다. 선택값·근거·날짜·영향ID를 담당 설계에 기록하고 구현을 진행한다. P-07은 결정 완료이고 첫 서버8조건은PASS다. F03 상위 기능은 브라우저/미리보기·전표 연결과 원장/보고서 경로의 후속 검증 전이다. 직전 거래처 화면 부분8PASS를 증빙 업로드 검증으로 사용하지 않는다.

## 목적과 범위

첫 실행은8조건7FAIL/1UNVERIFIED, 서버537PASS/24FAIL/24SKIP(24파일), 빌드 종료0다. 정상 multipart를400으로 거부하는 입력 계층부터 수리해야 한다. 실제 ClamAV7시험은PASS지만 R2 설정이 없어 실제 저장 시험은 미실행이다. 비통과2개 초과 중단 규칙을 적용했으며 [상세 실패/다음 수리 범위](03-evidence-foundation-design.md#첫-구현-검증과-중단-기록--2026-10-06)를 참조한다. F03을 완료로 보고하지 않는다.

영수증·세금계산서·첨부파일을 거래처 및 전표와 연결한다.

- 증빙 등록·조회와 첨부파일 관리
- 거래처·전표 연결과 원본 접근

## 입력과 결과

| 구분 | 내용 |

| 결과 | 증빙 목록·상세, 파일 접근 결과와 전표 연결 |

## 데이터와 처리 규칙

- 원본 파일은 비공개 객체 저장소에 저장하고 접근 시 회사별 권한을 확인한다.
- 파일 식별자, 업로드 정보와 거래처·전표 참조를 기록한다.
- 허용 파일 종류·크기·보존 및 삭제는 확정한 P-07을 입력 검증에 반영한다. 첫 서버 E1~E8과 첫 브라우저 B1~B7은 각각 구현·검증했고 파일 미리보기/전표 연결은 후속이다.
