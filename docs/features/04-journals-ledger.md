## 목적과 범위

균형 잡힌 전표와 분개를 기록하고 계정별 원장을 제공한다.

- 전표 작성·조회, 분개와 원장 조회
- 차변·대변 검증, 중복 및 동시 변경 처리

## 입력과 결과

| 구분 | 내용 |
| --- | --- |
| 입력 | 회사, 회계일자, 계정과목, 차변·대변 금액, 거래처와 증빙 |
| 결과 | 전표·분개, 계정별 원장과 잔액의 계산 근거 |

## 데이터와 처리 규칙

첫 회계 범위는 사용자 위임으로 확정한 [P-03 정책](07-financial-statements.md#사용자-위임으로-확정한-첫-회계-범위)을 따른다. 복식부기·발생주의 장부와 현금흐름표의 집계 목적을 구분한다. 금액 계산·저장·전달은 [확정한 금액 정책](08-platform.md#확정한-금액-정책)을, 계정과목·기초 잔액은 아래 P-10 정책을 적용한다. POSTED 전표의 분개장·계정별 원장 서버는 구현했고, 기초 잔액·마감·정정·보고서 집계는 아직 구현하지 않았다.

- 전표와 분개를 하나의 트랜잭션으로 저장한다.
- 금액과 반올림은 공통 시스템 문서의 기준을 사용한다.
- 회계일자와 등록·확정 시각을 구분하고 기초 잔액 처리 기준을 설계한다.
- 동일 제출 식별자의 재요청과 동시 수정의 충돌 처리 방식을 정한다.
- 확정·마감·정정은 승인 및 마감 문서의 상태 규칙을 참조한다.

## 확정한 계정과목과 기초 잔액

P-10 확정일: 2026-10-05. 사용자 근거: 금액·계정과목·기초 잔액 추천안을 제시한 뒤 “추천으로 하고 다음”으로 선택했다. 금액 공통 정책의 상세 값은 [공통 기반 문서](08-platform.md#확정한-금액-정책)를 참조하고 중복 정의하지 않는다.

| 항목 | 확정한 정책 |
| --- | --- |
| LEDGER-01 계정과목 | 일반기업회계기준 기반의 계정과목 템플릿을 제공하고 회사별 계정 추가·사용 중지를 허용한다. 이미 전표나 기초 잔액에 사용한 계정은 삭제하지 않는다. 사용 중지 계정도 과거 장부·보고서에서는 참조할 수 있어야 한다. 템플릿의 구체적 계정 목록과 재무제표·세무 매핑은 F04-01·F13에서 검토·버전 관리하며 과거 확정본을 바꾸지 않는다. |
| LEDGER-02 기초 잔액 | 첫 버전은 회계연도 시작 기준의 기초 잔액을 지원한다. 이전 연도 말 확정 잔액과 근거 시산표를 연결하고 일반 거래와 구분하여 한 번만 반영한다. 차변·대변 합계가 일치해야 하며 차액을 임의 계정으로 자동 보정하지 않는다. 일반 전표의 권한·승인·본인 승인 제한을 적용하여 승인된 잔액만 본 장부에 포함한다. 신규 회사의 잔액 0도 담당자가 명시적으로 확인한다. 연도 중간 잔액만 이관하여 누락된 당기 거래·손익을 완전한 연간 자료처럼 표시하는 기능은 지원하지 않는다. 중간에 도입한 회사는 연초 잔액과 이후 거래를 함께 입력·이관해야 한다. |

현재는 정책 확정이다. 기초 잔액의 데이터·승인·중복 방지·대사, 계정과목 관리 화면과 API는 F04-01·02·10 및 기반 단계에서 구현·검증한다.
