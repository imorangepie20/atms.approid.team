# 재무제표 개발 문서

[문서 인덱스](../README.md) · [전체 개요](../PROJECT_DECISIONS.md) · [개발 순서와 미정 사항](../ROADMAP.md)

문서 ID: F07

상태: P-03 첫 회계 범위 확정, 재무제표 기능 구현 전

이 문서의 상세 기능, 데이터와 완료 기준은 현재 요구사항을 개발 단위로 풀어쓴 설계안이다. 구현 후 검증 기준은 아직 실행 결과가 아니다. 사용자 확정사항과 기존 적용 기록은 별도로 표시한다.

## 목적과 범위

선택한 시점의 재무 상태와 기간별 재무 성과 및 현금 흐름을 조회한다.

- 기본 재무제표 5종과 검증·상세 자료 2종
- 전기 비교, 근거 조회와 확정 보고서 재현

## 입력과 결과

| 구분 | 내용 |
| --- | --- |
| 입력 | 회사, 회계연도, 기준일 또는 시작일·종료일, 비교 조건과 보고서 버전 |
| 결과 | 재무제표, 계정·원장·전표 근거와 Excel·PDF·인쇄 결과 |

## 데이터와 처리 규칙

- 기준일 잔액과 기간 변동의 집계 범위를 구분한다.
- 회계일자와 등록·확정 시각을 구분하고 현재 장부 조회와 과거 확정본을 구분한다.
- 계정 매핑, 계산·서식·규칙 버전과 입력 자료를 보고서에 연결한다.
- 현금흐름과 주석은 아래 P-03 정책을 적용하고, 항목별 계산·매핑·검증은 F07·F13에서 구현한다.

## 사용자 위임으로 확정한 첫 회계 범위

확정일: 2026-10-05. 사용자 지시: “다음 - 일반적으로 통용되는 방식으로 정하고 가자”. 직전 단계의 다음 결정인 **P-03 회계 범위**에 대한 위임으로 해석하고, 에이전트가 국내 일반기업을 위한 아래 범위를 선정했다. 각 값은 사용자 위임에 따른 프로젝트 결정이며 모든 기업의 법적 의무나 가장 많이 쓰이는 방식이라는 주장은 아니다. P-04 세무 범위와 P-10 금액 정책은 이번 결정에 포함하지 않는다.

| 항목 | 확정한 정책 |
| --- | --- |
| ACC-01 첫 기준·대상 | 일반기업회계기준(K-GAAP)을 적용하는 국내 비금융 법인의 회사 단위 회계를 먼저 지원한다. 비상장 중소·중견기업을 주요 제품 대상으로 삼되 비상장 여부만으로 적용 기준을 자동 판정하지 않는다. K-IFRS·중소기업회계기준·금융업·비영리 회계는 첫 지원 범위에 포함하지 않는다. |
| ACC-02 기록·인식 | 복식부기와 발생주의를 적용한다. 현금 수취·지급 시점과 거래의 회계 인식 시점을 구분한다. 현금흐름표는 발생주의 재무제표와 구분하여 실제 현금 흐름을 보고한다. |
| ACC-03 회계연도 | 기본값은 1월 1일~12월 31일이다. 회사 등록 시 실제 회계연도의 시작일·종료일을 지정하며 다른 결산월과 첫 사업연도의 짧은 기간도 회사의 기간 정보로 관리한다. 조회·마감·전기 비교는 해당 기간을 사용한다. 회계연도 변경은 적용 기간과 변경 이력을 남기고 과거 확정본을 바꾸지 않는다. |
| ACC-04 보고 단위 | 회사별 개별 재무제표를 제공한다. 제품에서 별도 보고 범위라고 부르는 회사 단위 보고이며 연결 재무제표는 첫 버전에서 제외한다. 연결 작성 의무가 있는 기업에 대해 이 기능으로 의무를 충족한다고 표시하지 않는다. |
| ACC-05 보고서 종류 | 재무상태표·손익계산서·현금흐름표·자본변동표·주석의 5종을 지원한다. 검증·상세 조회 자료로 시산표와 계정별 잔액 명세 2종을 제공한다. K-IFRS의 포괄손익계산서 추가 지원은 이번 범위에 포함하지 않는다. |
| ACC-06 현금흐름 | 영업활동 현금흐름은 간접법으로 작성한다. 투자·재무활동은 실제 현금 유입·유출을 거래 성격별로 분류하며 비현금 거래를 현금 유출입에 섞지 않는다. 직접법은 첫 버전에서 제외한다. 간접법은 기준서가 허용하는 방법 중 프로젝트가 선택한 방식이다. |
| ACC-07 주석 | 중요한 회계정책과 계정별 자동 집계 자료에 담당자가 작성하는 설명을 결합한다. 적용 기준과 회사 거래에 따라 필요한 우발사항·약정·특수관계자 등 주석을 포함하며 담당자 작성·검토·승인 상태를 관리한다. 필수 주석이 미완성인 보고서는 기준 준수 확정본으로 표시하지 않는다. 고정된 최소 주석만으로 모든 회사의 기준 준수를 보장하지 않는다. |
| ACC-08 조회·확정본 | 재무상태표는 기준일, 손익·현금흐름·자본변동은 시작일~종료일로 조회한다. 월·분기·연간 및 지정 기간, 전기 비교를 지원한다. 확정 전표가 기본 집계 대상이며 미확정 전표 포함 결과는 예상 보고서로 구분한다. 과거 확정본은 당시 입력·규칙·계정 매핑·서식 버전과 함께 보존한다. |
| ACC-09 양식·출력 | 일반기업회계기준을 바탕으로 항목·주석·비교기간을 갖춘 회사용 보고 양식을 제공하고 웹 조회·Excel·PDF·인쇄를 지원한다. 보고 양식은 버전으로 관리한다. 기관별 정식 제출 서식·전자신고·자동 제출은 첫 범위에서 제외한다. 파일 출력 가능 여부만으로 정식 제출 요건 충족을 주장하지 않는다. |
| ACC-10 설정·규칙 경계 | 공통 기본값은 하나의 공통 설정 파일에서 관리하되 회사별 실제 회계연도는 회사 업무 데이터로 저장한다. 적용 기간에 맞는 승인된 회계 규칙·매핑·서식 버전은 F13에서 관리하며 최신 버전으로 과거 결과를 덮어쓰지 않는다. 통화·소수 자릿수·반올림·계정과목·기초 잔액 정책은 P-10에서 별도로 확정한다. |

공식 근거는 [한국회계기준원 일반기업회계기준 목록](https://www.kasb.or.kr/front/board/List3003.do)의 다음 자료를 확인했다. 확인일은 2026-10-05이며 목록에 게시된 문서의 개정 표시는 적용 사업연도의 규칙 선택을 대신하지 않는다.

- **제2장 재무제표의 작성과 표시**, 목록의 2023년 개정 반영본: 문단 2.16의 기본 재무제표 5종, 2.63의 영업활동 직접법·간접법 선택, 2.65의 간접법을 확인했다. 문단 2.8에 따라 기준의 모든 요구사항을 따르지 않으면 기준 준수라고 기재할 수 없다.
- **재무회계개념체계**, 목록의 2019년 개정 반영본: 문단 66~67의 발생주의와 현금흐름표 예외를 확인했다.

한국회계기준원 목록은 일반기업회계기준을 외부감사법 적용 기업 중 K-IFRS를 적용하지 않는 기업의 기준으로 안내한다. 제품의 지원 대상 결정과 개별 회사의 법적 적용 기준 판정은 구분한다. 회계연도 기본값, 간접법 선택, 출력 형식과 첫 지원 제외 범위는 이 근거를 참고한 프로젝트 선택이다. 세무 신고 기간이나 세법 적용을 이 결정만으로 확정하지 않는다.

영향 작업: F01-01, F04-01~10, F07-01~14, F08-11·12, F13-01~03. [확정 기록](../PROJECT_DECISIONS.md#사전-결정-확정-기록)과 [구현 계획](../IMPLEMENTATION_PLAN.md)을 함께 참조한다. 현재는 범위 결정이며 계산·저장·화면·출력·주석 승인 기능은 구현 전이다.

## 기존 결정과 상세 요구사항

아래 내용은 종합 문서에서 옮긴 결정 및 요구사항이다. 기술 버전과 적용·검증 기록의 기준일은 2026년 10월 5일이며, 이번 문서 분리 작업에서 기능이나 외부 서비스 상태를 재검증한 결과는 아니다.

### 재무제표 구현 범위

사용자가 요구한 특정 시점의 재무 상태 조회를 위해 재무제표 기능을 구현한다. P-03으로 확정한 기본 5종과 검증·상세 조회 자료 2종은 아래와 같다. 실제 계산식·계정 매핑·주석 항목 및 출력 레이아웃은 위 정책에 맞추어 F07·F13에서 설계하고 검증한다.

| 보고서 | 조회 기준 | 주요 내용 |
| --- | --- | --- |
| 재무상태표 | 특정 기준일 | 해당 날짜의 자산, 부채와 자본 잔액 |
| 손익계산서 | 시작일과 종료일 | 해당 기간의 수익, 비용과 손익 |
| 현금흐름표 | 시작일과 종료일 | 해당 기간의 영업, 투자 및 재무 활동별 현금 흐름 |
| 자본변동표 | 시작일과 종료일 | 기초 자본에서 기말 자본까지의 변동 |
| 주석 | 보고 기준일과 대상 기간 | 회계정책, 필요한 공시와 보고서별 상세 근거 |
| 시산표 | 기준일 또는 대상 기간 | 계정별 차변·대변과 잔액의 검증 자료 |
| 계정별 잔액 명세 | 특정 기준일 | 보고서 항목을 구성하는 계정 및 전표 상세 |

초기 기능 구분에는 [IFRS Foundation의 IAS 1 설명](https://www.ifrs.org/issued-standards/list-of-standards/ias-1-presentation-of-financial-statements/)과 [IAS 7 설명](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/)을 참고했다. 현재 첫 지원 기준은 위 P-03의 일반기업회계기준이며 이 참고 이력을 K-IFRS 지원 확정으로 해석하지 않는다.

구현 시 다음 조건을 설계하고 검증한다.

1. **조회 조건**: 회사, 회계연도, 기준일 또는 시작일과 종료일, 비교 기준일 또는 비교기간, 통화 및 표시 단위를 지정한다. 회사별 회계연도 시작일을 반영한다.
2. **전표 포함 기준**: 기본 재무제표는 확정된 전표를 회계일자 기준으로 집계한다. 기초 잔액, 결산 조정과 손익의 자본 반영을 일관되게 처리한다. 미확정 전표를 포함한 조회는 별도 예상 보고서로 표시한다.
3. **과거 결과 재현**: 회계일자와 시스템 등록·확정 시각을 구분한다. 현재 장부로 과거 기준일을 재조회한 결과와 당시 확정한 보고서를 구분하고, 확정 보고서는 전표 집합 또는 집계 결과, 계정 매핑, 계산 및 서식 버전을 보관해 재현한다. 소급 입력이나 정정이 있으면 새 보고서 버전을 만들고 기존 확정본을 남긴다.
4. **분류 정책**: 계정과목을 재무제표 항목에 연결하고 매핑 버전을 기록한다. 현금흐름은 현금 계정의 총증감만으로 분류하지 않고 거래 성격에 따른 분류 정책을 둔다. 비현금 거래와 필요한 환율 변동 등 조정도 구분한다. 영업활동은 P-03의 간접법을 적용하며 실제 분류·조정 계산은 구현 단계에서 검증한다.
5. **대사와 검증**: 자산 합계와 부채 및 자본 합계의 일치, 시산표의 차변·대변 합계 일치, 현금흐름표의 기말 현금 및 현금성자산과 재무상태표 대응 잔액의 일치를 검증한다. 자본변동과 손익 연결도 동일한 회계기준으로 대사한다.
6. **근거 조회와 출력**: 보고서 항목에서 계정별 잔액, 원장, 전표와 증빙으로 이동할 수 있게 한다. 전기 비교, Excel 및 PDF 출력과 인쇄를 지원하는 방향으로 설계한다. 주석에는 자동 집계 자료와 담당자의 작성·승인이 필요한 내용을 구분한다.
7. **마감 상태 표시**: 중간 기준일의 미결산 조회와 결산 조정을 반영한 확정 보고서를 구분하고, 회사, 기준일·기간, 생성 시각과 보고서 버전을 표시한다. 조회와 출력에 동일한 회사별 권한을 적용한다.

재무제표 계산 및 화면은 아직 구현하지 않았고 실제 장부를 통한 대사도 수행하지 않았다. 회계기준·보고 단위·회계연도·현금흐름 작성 방식·주석·출력 범위는 P-03으로 확정했으며 범위 결정만으로 기준 준수나 출력 기능 구현을 검증한 것은 아니다.

## 후속 구현 설계와 남은 결정

- P-03 정책에 따른 계산식·계정 매핑·회사별 필수 주석·검토와 승인 흐름·출력 레이아웃의 상세 설계 및 검증
- 금액·계정과목·기초 잔액은 이후 확정한 [P-10 금액 정책](08-platform.md#확정한-금액-정책)과 [장부 정책](04-journals-ledger.md#확정한-계정과목과-기초-잔액)을 적용해 구현·검증함. 세무 연계는 [P-04 첫 세무 범위](06-tax.md#사용자-위임으로-확정한-첫-세무-범위)를 따름. 기관별 정식 제출 서식은 첫 범위에 포함하지 않음
