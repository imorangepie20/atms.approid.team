P-01 운영 모델은 SaaS로 확정했다. 외부 고객사가 가입해 각자 회사의 자료를 관리한다. 확정일·사용자 선택 근거와 영향 작업은 [사전 결정 확정 기록](PROJECT_DECISIONS.md#사전-결정-확정-기록)을 따른다. P-02 웹 인증·역할과 P-03·P-04 첫 회계·세무 범위도 사용자 선택·위임으로 확정했다. [구현 파일·실행 결과](features/08-data-money-design.md)를 참조한다. 다음은 F01·F08-13 회사·인증·권한과 감사 이력이다. 새 코드 작성 전 해당 설계와 수정·생성 파일 목록을 제시하고 범위를 확인한다. 작업별 범위 확인·검증과 P-05~09의 추가 선행 조건은 유지한다.

P-02의 로그인 방식은 이메일 + 비밀번호로, 역할 구성은 외부 세무사를 포함한 5개로 확정했다. 전표 본인 승인은 회사별 설정으로 하며 기본값은 본인 승인 금지로 확정했다. 같은 회사에서 한 사용자의 여러 역할 겸임을 허용하며 본인 승인 정책은 그대로 적용한다. 외부 세무사의 기본 권한은 자료 조회·보고서 다운로드·증빙 등록·전표 초안 작성·수정이며, 이 역할 자체에는 전표 승인·회사 관리 권한을 포함하지 않는다. 남은 인증·역할 정책은 사용자 위임으로 [인증 기본 정책](features/01-company-access.md#사용자-위임으로-확정한-인증-기본-정책)과 [마감·정정 권한](features/05-approval-closing.md#확정한-마감과-정정-권한)을 채택했다. P-02는 정책 확정이며 첫 인증·세션·권한·감사 서버 부분의 구현·검증을 완료했다. 가입·이메일·회사 관리·실제 화면은 후속이다. 확정 근거와 영향 작업은 위 확정 기록을, 역할 목록과 권한은 [회사와 사용자 권한](features/01-company-access.md#확정한-역할-구성)을 참조한다.

외부 세무사 회사 접근은 관리자 초대 + 세무사 접근 요청 후 회사 관리자 승인으로 확정했다. 회사별로 권한을 부여하고 해당 회사 관리자가 회수할 수 있으며 다른 회사의 접근 권한은 자동으로 생기지 않는다. 이전 접근 요청 제외 지시는 이 결정으로 대체됐다. 근거는 [사전 결정 확정 기록](PROJECT_DECISIONS.md#사전-결정-확정-기록)을 따른다.

회사 관리자 기본 권한은 회사 설정·사용자 초대·역할 관리·본인 승인 설정 변경 + 회계 담당자·승인자 권한 기본 포함으로 확정했다. 회계 담당자·승인자·조회 전용의 기본 권한도 [기본 권한표](features/01-company-access.md#확정한-기본-권한표)로 확정했다. 본인 승인 정책은 관리자에게도 그대로 적용한다. 추가 권한은 위 마감·정정 권한 문서로 확정했다. 근거는 위 사전 결정 확정 기록을 따른다.
